# E-Commerce Sales & Customer Analytics
An analytics project using SQL and Excel to analyse e-commerce sales, customer behaviour, and product performance.

## Project Overview
This project analyses a synthetic e-commerce dataset containing 500 transactions.
The objective is to identify sales trends, understand customer behaviour, evaluate product performance, and generate business insights using SQL and Excel.

## Tools & Technologies
- SQL
- Excel
- SQLite / MySQL
- Data Analysis
- Data Visualization

## Business Questions
The analysis focuses on:
- What are the monthly revenue trends?
- Which product categories generate the most revenue?
- Which products are the top performers?
- Which regions generate the highest sales?
- How many customers make repeat purchases?
- What is the average order value?
- What percentage of revenue does each category contribute?
