# 📌 Project Overview

This project analyses a synthetic e-commerce dataset containing **500 transactions**.

The objective is to identify sales trends, understand customer behaviour, evaluate product performance, and generate actionable business insights using SQL and Excel.

The analysis combines SQL-based data exploration with an Excel KPI dashboard to transform raw transaction data into meaningful insights.

# ❓ Business Questions

The analysis focuses on:

- What are the monthly revenue trends?
- Which product categories generate the most revenue?
- Which products are the top performers?
- Which regions generate the highest sales?
- How many customers make repeat purchases?
- What is the average order value?
- What percentage of revenue does each category contribute?

---

# 🔍 SQL Analysis

SQL was used to analyse transaction-level data and answer business questions.

The analysis includes:

- Aggregations using `SUM()`, `COUNT()`, and `AVG()`
- `GROUP BY` for category, product, customer, and regional analysis
- Filtering using `WHERE`
- Conditional analysis using `CASE`
- Common Table Expressions (CTEs)
- Window functions for customer and sales trends
- Sorting and ranking results

---

# 📈 Key Analysis Areas

### Monthly Revenue

Analysed revenue across different months to identify sales trends and high-performing periods.

### Category Performance

Compared revenue generated by different product categories to identify the strongest categories.

### Product Performance

Ranked products based on sales and revenue to identify top-performing products.

### Regional Analysis

Compared sales across different regions to understand geographical performance.

### Customer Behaviour

Analysed customer purchase frequency to identify repeat customers and purchasing patterns.

### Revenue Contribution

Calculated the percentage contribution of each product category to overall revenue.
