# E-Commerce Sales & Customer Analytics

## Overview
Portfolio analytics project using a **synthetic** e-commerce dataset to answer business questions with SQL and Excel.

## Business Questions
- How does revenue change over time?
- Which products/categories drive revenue?
- Which regions perform best?
- What is average order value?
- Which customers are repeat buyers?
- How is revenue distributed across categories?
- How do products rank within categories?

## Tools
SQL • Excel • Data Analysis • Data Visualization

## SQL Concepts
Aggregations, GROUP BY/HAVING, subqueries, CTEs, window functions and RANK().

## Excel
Transaction data, KPI summary, monthly revenue analysis, category analysis and charts.

## How to Use
1. Import the CSV into SQLite/MySQL.
2. Create the table with `sql/schema.sql`.
3. Run `sql/analysis_queries.sql`.
4. Open the Excel workbook.
